# 2026-07-15 Markdown 段落自动排版

## 目标

在不调用 LLM 的前提下，自动清理 LiteParse 与本地 OCR 输出中的视觉换行，让同一自然段复制到翻译网页或交给 Agent 时保持连续，同时不破坏 Markdown 结构。

## 实现

- 新增 `src/markdown_reflow.py`，使用确定性规则处理中文、英文和 OCR 文本。
- 合并连续正文行；对被空白行隔开的内容，仅在上一行足够长、没有句末标点且下一行不是新结构时续接。
- 保留标题、列表起点、表格、图片、引用、代码围栏、公式、分页和扫描书页码边界。
- 英文大写记录起点按新条目保留，避免把作者列表等独立记录拼成一个段落。
- `config.json` 新增并默认开启 `reflow_markdown: true`。
- 普通 PDF 在发布 `.md` 前排版；HTML 仍使用原始解析内容。扫描书在写入按页 OCR Markdown 前排版。
- 输出仍先写临时文件，校验成功后原子发布；全程本地运行，无 LLM、无上传。
