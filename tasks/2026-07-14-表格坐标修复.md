# 表格坐标修复

## 问题

LiteParse 2.4.0 在一份横向密集四列表格中只把“序号、论文名称”保留在 Markdown 表格内，把“作者单位、作者”按列抽成了表外段落。HTML 渲染器无法从错误的中间结构恢复行列关系。强制 OCR 的识别结果更差。

## 改动

- 新增 `src/table_repair.py`，检测数据整列为空的异常 Markdown 表格。
- 异常时仅对对应 PDF 页请求 LiteParse JSON 坐标，按表头横坐标和逐行锚点重建单元格。
- 重建前校验至少两个表头、全部行锚点、已有单元格和缺失列填充率；不满足条件时保留原结果。
- 仅在表格单元格内清理中文断词伪空格，保留中英文必要空格。
- 坐标临时文件和修复后的 Markdown 都先写临时文件，再原子替换。

## 验证

- 9 项单元测试通过。
- 真实 PDF 后台端到端处理通过，日志确认清理 2 处断词空格并修复 1 个异常表格。
- HTML 中两张表均为四列表头，共 16 行数据；作者单位和作者逐行对应。
- 浏览器打印为 3 页并逐页视觉检查，第 2、3 页无表外散落文字、无缺列或内容重叠。
- 后台监控重启后保持 `PPID=1`。

## 结果

修复版输出：`outbox/中国电机工程学会核能发电分会关于公布2026年学术论文评选结果的通知(3)(1)-表格修复版.html`
