# 设计与运行说明

## 处理流程

```text
inbox/*.pdf
    |
    | 文件大小与修改时间连续稳定 5 秒
    v
processing/*.pdf
    |
    |-- 先用 LiteParse --no-ocr
    |-- 统计真实内容，不计 Markdown 围栏/图片引用/HTML 标签
    |
    |-- [有文字层] Markdown + 内嵌位图
    |       |-- 表格断词清理与异常列检测
    |       |-- 必要时按 LiteParse JSON 坐标重建表格
    |       `-- 本地规则重排版、图片 Base64 嵌入
    |
    `-- [无文字层长篇扫描书] 原页保真模式
            |-- Poppler 本地生成每页 JPEG
            |-- Tesseract PSM 3 生成折叠辅助文字
            `-- 原页图 Base64 嵌入单 HTML，OCR 不参与可见排版
    v
outbox/*.html + outbox/*.md + 可选 outbox/*_assets/ + processed/*.pdf
    |
    `-- 异常时 -> failed/*.pdf + failed/*.error.txt
```

## 可靠性措施

- 稳定时间门槛防止解析仍在复制的 PDF。
- 从 `inbox/` 到 `processing/` 使用同文件系统原子移动，防止重复领取。
- 单实例文件锁防止两个监控器同时处理。
- 结果先写 `.partial`，成功后才原子更名。
- HTML 与 Markdown 来自同一份解析中间结果；发布任一输出失败时会回收已发布的同批结果，不留半套产物。
- 普通 PDF 的 Markdown 图片仅复制已被实际引用的安全项目内文件，并重写为同名 `_assets/` 相对路径；外部 URL 和越界路径不会被复制。
- HTML 为单文件，CSS 和可提取图片全部内嵌，不依赖 CDN、外部字体或 JavaScript。
- 扫描书的可见正文为原页图，表格、图表、公式和标注不由 OCR 重排；OCR 失败只会让对应页缺少辅助文字，不会丢失页面。
- 扫描页 JPEG 带固有宽高，便于大文档稳定滚动和按页锚定；打印 CSS 将每个原页映射到一个 A4 页面。
- 临时 Markdown 和图片仅在 `processing/` 存在，HTML 原子发布后立即清理。
- 表格修复只在强异常信号出现时触发额外的坐标解析；至少校验两个表头、逐行锚点和已有单元格，校验失败则保留原结果。
- 进程异常退出后，下次启动会恢复 `processing/` 中的 PDF。
- 同名文件使用数字后缀，不覆盖旧输出或旧原文。
- 解析超时、空输出和 LiteParse 异常均会进入可审计的失败区。
- 日志使用 1 MB x 4 的轮转上限。

## macOS 后台运行选型

项目在 `/Users/joe/Documents/` 下，macOS TCC 会拒绝无交互 `launchd` 进程读取该路径。实测退出原因为：

```text
python3: can't open file '.../src/watcher.py': [Errno 1] Operation not permitted
```

备选方案包括把运行时复制到工作区外，或给 Python “完全磁盘访问”。前者违反项目文件集中规则，后者权限过宽。因此选择由当前已授权用户会话启动独立后台进程，并提供双击启停入口。

实际启动入口通过 macOS Terminal GUI 运行。验收时已确认后台进程的 `PPID=1`，并在新的命令会话中再次投递真实 PDF 成功，避免把 Agent 工具进程树内的短暂存活误当为长驻。

## 配置关键项

- `settle_seconds`：文件稳定等待。
- `output_format`：默认为 `html`；仍可手动改为 `markdown` 或 `text`。
- `ocr_mode`：`auto`、`always` 或 `never`。
- `ocr_language`：Tesseract 语言组合，当前为 `chi_sim+eng`。
- `minimum_text_characters`：自动模式中触发 OCR 的最小文字数字字符数。
- `parse_timeout_seconds`：单文件 LiteParse 最长运行时间。
- `repair_tables`：默认为 `true`；启用表格断词清理和高置信度坐标重建。
- `keep_markdown`：默认为 `true`；在 HTML 之外同时发布 Agent 可直接使用的 Markdown。
- `scan_book_mode`：是否自动启用扫描书原页保真 HTML。
- `scan_book_min_pages`：保真路由的最小页数，默认 10。
- `scan_book_dpi` 与 `scan_book_jpeg_quality`：原页图清晰度与体积平衡，默认 120 DPI / 68。
- `scan_book_ocr_text`：是否生成不影响排版的折叠辅助 OCR 文字。
- `lit_binary` 和 `required_lit_version`：固定本机 LiteParse 2.4.0 路径与版本检查。
