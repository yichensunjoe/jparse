# JParse — Windows 版快速上手与使用指南

## Windows EXE（推荐普通用户使用）

从 GitHub Actions 成功构建的 `JParse-Windows-x64` 构件中下载并解压
`JParse-Windows-x64.exe`，在 **64 位 Windows 10/11** 上双击运行。首次启动需要
将内置运行环境展开到当前用户目录，可能需要几分钟；之后再次启动会复用该环境。
无需单独安装 Python 或 Java。工作台使用已安装的 Microsoft Edge 或 Google Chrome。

工作文件保存在 `%LOCALAPPDATA%\JParse\data\`：`inbox` 为投递目录，`outbox`
为输出目录，`processed` 和 `failed` 分别保存处理成功和失败的原件，`logs` 保存
有大小上限的运行日志。运行环境位于同一 `JParse\r\` 目录，不要在程序运行
期间删除。关闭窗口不会自动停止后台服务，注销用户会话后会停止。

PDF 的识别和排版在本机进行，原始 PDF 不上传；默认 Bing 翻译需要联网，提取的
文本会发送至所选翻译服务。此 EXE 未进行商业代码签名，Windows 可能显示安全提示。
Windows CI 验收范围以工作流实际结果为准；扫描件识别效果取决于文档本身和可用的 OCR 能力。
EXE 包含位图图例所用的 PaddleOCR 运行环境与模型。它没有内置旧版 LiteParse
命令行工具和本地离线翻译模型，依赖这两项的旧版模式不能视为开箱即用。CI 验收
带文字层 PDF 的解析、在线翻译和独立位图 OCR；无法提取文字的纯扫描页会明确报错，
原件移入 `failed`，不会生成空白译文并标记成功。

下面是面向源码开发者的旧版 Python 与批处理启动方式。

欢迎使用 **JParse**（Windows 版本）。JParse 是专为学术论文、技术规范及图书文献打造的智能重构、原位版面识别与中英翻译排版引擎。

Windows 版本基于确定性算法与现代 Web/Chromium 原生应用模式，无需安装任何笨重的第三方框架，**直接利用 Windows 10/11 内置的 Microsoft Edge 或 Google Chrome 呈现独立桌面视窗**，提供与 macOS 原生客户端一致的丝滑交互与高保真排版体验。

## ⚡️ 三步快速上手

### 步骤 1：准备 Python 环境
- 推荐使用 **Python 3.10 ~ 3.12**。
- 如果您的电脑尚未安装 Python，可以在 PowerShell 或终端中直接运行：
  ```powershell
  winget install Python.Python.3.12
  ```
  或者前往 [Python 官方网站](https://www.python.org/downloads/) 下载安装包。
  > ⚠️ **关键注意**：安装时请务必勾选 **"Add python.exe to PATH"**（将 Python 添加到系统环境变量）。

### 步骤 2：一键自动配置环境
进入 JParse 项目根目录，**双击运行**：
👉 **`一键安装环境-Windows.bat`**

脚本将自动完成：
1. 自动探测系统 Python；
2. 在本地创建独立的隔离虚拟环境（`venv\`）；
3. 自动安装 PyMuPDF、fonttools 等核心排版库；
4. 检查系统 Chromium 引擎与可选依赖，给出就绪状态。

### 步骤 3：双击启动应用
环境配置完成后，您有以下两种启动方式：
- **方式一（推荐）**：双击 **`启动JParse桌面应用(无黑框).vbs`**
  - 完全静默启动，**无任何黑框命令行窗口干扰**，直接弹窗呈现原生质感的 JParse Studio 桌面应用！
- **方式二**：双击 **`启动JParse桌面应用.bat`**
  - 启动桌面应用并保留控制台日志，方便查看后台任务实时流。

## 🖥 两种使用方式

### 模式 A：交互式桌面 Studio（所见即所得）
1. 双击打开 `启动JParse桌面应用(无黑框).vbs`；
2. 直接将单个 PDF 文献、批量 PDF 或整个文件夹拖拽至应用窗口；
3. 系统自动分析版面类型（现代矢量文献 / 扫描书籍），执行原位擦除、中英文对照排版、表格原位回贴与图例原位重绘；
4. 点击列表中交付产物旁边的“打开”，即可直接在默认 PDF 阅读器或浏览器中查阅成果。

### 模式 B：投递箱自动静默监控（批处理流水线）
1. 双击 **`打开PDF投递箱.bat`**（打开 `inbox\` 文件夹）；
2. 把需要处理的 PDF 文献复制或拖入投递箱；
3. 双击 **`启动自动识别.bat`** 启动后台监控流水线；
4. 双击 **`打开识别结果.bat`**（打开 `outbox\` 文件夹），在处理完成后自动查收同名中文精译版、双语对照版 PDF 以及排版完毕的 HTML 与纯净 Markdown！
5. 需要停止时，双击 **`停止自动识别.bat`** 即可。

## 🔧 可选进阶功能支持

JParse 核心提取、段落自动重排与单双语排版均为本地原生运行。如需启用更加极致的高级功能，可根据需要配置：

1. **学术级复杂表格抽取（OpenJDK）**：
   - 安装 [Eclipse Temurin OpenJDK 17+](https://adoptium.net/) 或运行 `winget install EclipseAdoptium.Temurin.17.JDK`。JParse 会自动识别 Java 并在复杂双栏/跨页表格时启用 OpenDataLoader-PDF 拓扑流抽取。
2. **出版级无头打印渲染（Microsoft Edge / Google Chrome）**：
   - JParse 原生支持 Windows 10/11 自带的 Edge 浏览器（无需额外安装）或 Google Chrome，自动调用无头 Chromium 输出出版级高清矢量 PDF。
3. **完全离线本地翻译引擎（可选）**：
   - 默认模式使用 Bing 神经翻译服务（仅传输提取文字，原始 PDF 永不上传）。如需内网离线翻译，可在偏好设置中切换至本地服务。

## ❓ 常见问题 (FAQ)

- **Q: 双击 `.bat` 提示中文乱码或闪退怎么办？**
  - 所有 `.bat` 文件均已内置 `chcp 65001`（UTF-8 代码页）。请确保通过 Windows 文件资源管理器直接双击打开，或者在运行前先执行一次 `一键安装环境-Windows.bat`。
- **Q: 为什么没有黑框弹出？**
  - 如果双击的是 `启动JParse桌面应用(无黑框).vbs`，该脚本特别设计为静默后台运行，并直接拉起独立的 JParse 桌面视窗，属正常优秀体验。如需观察实时运行输出，双击 `.bat` 版本即可。
- **Q: 原始 PDF 是否会被上传到云端？**
  - **绝不上传。** 所有的 PDF 文件解析、版面分析、图像隔离重绘与排版重构都在您本机的 Windows 系统内完全本地完成。
